# Custom System Font Configuration for Windows

Apply a custom system-wide interface font across Windows.

---

## Instructions

1. Open `change.windows.font.reg` in a text editor.
2. Replace occurrences of `Ubuntu` with your installed font family name.
3. Save and execute `change.windows.font.reg`, confirming the registry import.
4. Log out and log back in or restart your computer.

### Restoring Default Fonts

To restore the default Windows system font (Segoe UI), double-click and execute
`restore.default.windows.font.reg`.
