# Warning: Avoid Official ProtonVPN Linux Desktop & CLI Apps

> [!WARNING] **Do Not Install Official ProtonVPN Desktop or CLI Packages on Linux.**
>
> The official ProtonVPN Linux applications (GUI, CLI, and community Python wrappers) have
> severe instability issues. They frequently crash, experience memory leaks, and often
> leave system networking, firewall tables, and DNS resolvers corrupted even after
> uninstallation.
>
> **Recommended Alternative**: Download standard OpenVPN configuration files (`.ovpn`) or
> WireGuard configurations directly from your ProtonVPN account dashboard, and connect
> natively via NetworkManager, WireGuard, or OpenVPN.
