# ProtonVPN CLI Connection Commands

Commands for managing ProtonVPN connections via the official command-line interface.

---

## Commands

```bash
# Initialize ProtonVPN client configuration (first-time setup):
sudo protonvpn init

# Connect to the fastest available server:
protonvpn connect -f

# Reconnect or reconnect to the last used server:
protonvpn reconnect

# Disconnect the active VPN session:
protonvpn disconnect

# Display current connection status and IP:
protonvpn status

# Reconfigure client preferences:
protonvpn configure
```
