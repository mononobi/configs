# Custom Commands Setup

The `bin` folder contains some shortcut commands which can be copied into the `.local` directory in your user's home directory.

## Installation

1. Execute the following command to copy the files:

```bash
cp -r bin ~/.local
```

2. Then, make the copied files executable:

```bash
chmod +x ~/.local/bin/*
```

3. You should log out and log in again for the changes to take effect.

Now you can execute those commands in the terminal from anywhere.
