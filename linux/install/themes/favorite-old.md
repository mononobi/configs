## Important Notes

> **Warning:** After setting these values in the Tweaks app, you should never open the **"Appearance"** tab in Ubuntu settings. Otherwise, these settings will be reverted back to default, and you will have to do it again.

In the Tweaks app, the full name of the icon packs may not be visible. To see the full name of the currently selected pack, execute this command in a terminal:

```bash
gsettings get org.gnome.desktop.interface icon-theme
```
