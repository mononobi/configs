# GTK Theme Dependencies Installation Guide

This guide provides the necessary commands to install GTK theme dependencies for both Debian-based and Arch-based Linux distributions.

## Debian-Based Distributions

Run the following commands to install the dependencies on Debian, Ubuntu, Linux Mint, or other Debian-based systems:

```bash
sudo apt-get install libgtk-3.0
sudo apt-get install gnome-themes-extra
sudo apt-get install gtk2-engines-murrine
sudo apt-get install sassc
```

## Arch-Based Distributions

Run the following commands to install the dependencies on Arch Linux, Manjaro, EndeavourOS, or other Arch-based systems:

```bash
sudo pacman -S gtk3
sudo pacman -S gnome-themes-extra
sudo pacman -S gtk-engine-murrine
sudo pacman -S sassc
```
