# Install GTK Theme

This guide explains how to install the Graphite GTK Theme.

## Prerequisites

First, ensure you install the dependencies outlined in the
[`install.gtk.dependencies.md`](/linux/install/themes/applications/install.gtk.dependencies.md)
file.

## Installation Steps

1. Extract the `Graphite-GTK-Theme.zip` file.
2. Open a terminal and navigate to the extracted theme folder.
3. Execute one of the following commands based on your preferred style:

### Dark Gray Version (Recommended)

To install the recommended dark gray version, run:

```bash
./install.sh -t all -s compact --tweaks rimless --tweaks normal
```

### Pure Black Version

To install the pure black version, run:

```bash
./install.sh -t all -s compact --tweaks rimless --tweaks normal --tweaks black
```
