# Icon Theme Installation

To install the Material Originals Icons, follow these steps:

1. Extract the `Material-Originals-Icons-Blue.zip` file.
2. Put the top two folders into the following directory:
   ```bash
   ~/.icons
   ```

> **Important:** Both folders must be copied, otherwise the icon theme may not work.

3. Open **GNOME Tweaks** and change the icons in the **Appearance** tab.

> **Tip:** You can also copy those two folders into `/usr/share/icons` to make the theme
> accessible to all users.
