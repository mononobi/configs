# AWS Elastic Beanstalk CLI (EB CLI)

Download the code from: [aws/aws-elastic-beanstalk-cli-setup](https://github.com/aws/aws-elastic-beanstalk-cli-setup)

## Install Dependencies

```bash
sudo apt-get install build-essential zlib1g-dev libssl-dev libncurses-dev libffi-dev libsqlite3-dev libreadline-dev libbz2-dev
```

## Install EB CLI

```bash
python3.7 aws-elastic-beanstalk-cli-setup/scripts/ebcli_installer.py
```
