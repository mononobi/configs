# Install Virtual MIDI Piano Keyboard (VMPK)

Virtual MIDI Piano Keyboard (VMPK) is a full-featured MIDI event generator and controller. It supports ALSA/JACK MIDI, soundfonts, customizable key bindings, and velocity curves.

## Installation Commands

Run the following commands to install VMPK:

```bash
sudo apt-get update
sudo apt-get install -y vmpk
```
