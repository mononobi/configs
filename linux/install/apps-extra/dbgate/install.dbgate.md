# DbGate Installation

DbGate is an open-source, cross-platform database management tool. It supports all major
database systems and is considered a close second to DBeaver regarding features.

## Recommended Installation (DEB)

1. Go to the [DbGate Download Page](https://dbgate.org/download) and download the `.deb`
   version.
2. Execute the following command to install the downloaded package (replace
   `FILE_NAME.deb` with the actual file name):

```bash
sudo apt install ./FILE_NAME.deb
```

## Snap Installation (Not Recommended)

Alternatively, you can install DbGate using Snap:

```bash
sudo snap install dbgate
```
