# FreeCAD Installation Guide

FreeCAD is the open source alternative to AutoCAD.
[Official Downloads Page](https://www.freecadweb.org/downloads.php)

## Install with Flatpak (Recommended)

```bash
flatpak install flathub org.freecad.FreeCAD
```

## Install from APT Repository (Ubuntu <= 22.04)

```bash
sudo apt-get install freecad
```

## Install on Arch-based Linux

```bash
sudo pacman -S freecad
```
