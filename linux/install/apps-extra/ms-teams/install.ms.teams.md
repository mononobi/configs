# Install Microsoft Teams

This guide covers the options for installing or setting up Microsoft Teams on Linux.

## Install as PWA Web App (Recommended)

You can install Microsoft Teams as a Progressive Web App (PWA) by visiting the official Teams
web interface via a compatible browser:

[https://teams.cloud.microsoft](https://teams.cloud.microsoft)

## Install using Flatpak (Not Recommended)

Alternatively, you can install the community-maintained `teams_for_linux` client via Flatpak
using the following command:

```bash
flatpak install -y flathub com.github.IsmaelMartinez.teams_for_linux
```
