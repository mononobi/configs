# Install Grub Customizer

This app lets you customize boot menu entries.

## Older Versions of Ubuntu (19.04 or older)

If you are on older versions of Ubuntu, execute the following commands to add the PPA:

```bash
sudo add-apt-repository ppa:danielrichter2007/grub-customizer
sudo apt-get update
```

## Installation

Now, install the application:

```bash
sudo apt-get install grub-customizer
```
