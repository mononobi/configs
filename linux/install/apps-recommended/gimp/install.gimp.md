# GIMP Installation Guide

## Recommended Method: Flatpak (Latest Version)

To install the latest version of GIMP using Flatpak, run the following command:

```bash
flatpak install flathub org.gimp.GIMP
```

## Alternative Method: APT (Not Recommended - Old Version)

> **Warning:** This method is not recommended as it typically installs an older version of
> GIMP.

To install GIMP using APT, run the following command:

```bash
sudo apt-get install gimp
```
