# Windows 11 Installation on Unsupported Hardware using Ventoy

> **Note:** If you want to install Windows 11 on hardware that is not officially supported by Microsoft (e.g., no TPM, no Secure Boot, less than 4GB RAM, or less than 64GB storage), follow this step after creating your bootable disk.

Copy the `files/ventoy.json` file into the `ventoy` folder on the first partition of your USB media (the partition that also contains the Windows image ISO file).
