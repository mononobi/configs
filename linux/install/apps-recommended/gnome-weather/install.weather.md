# Install GNOME Weather

You can install GNOME Weather using the package manager. There are two methods, though
using `apt` is the recommended approach.

## Recommended Method

Use the APT package manager to install GNOME Weather:

```bash
sudo apt-get install gnome-weather
```

## Not Recommended Method

Alternatively, you can install it using Flatpak, although this is not recommended:

> **Note**: This method is generally not recommended compared to the standard APT
> installation.

```bash
flatpak install flathub org.gnome.Weather
```
