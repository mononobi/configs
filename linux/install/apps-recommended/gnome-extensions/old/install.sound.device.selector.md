# Install Sound Output Device Chooser GNOME Extension

This guide covers the installation and configuration of the Sound Output Device Chooser extension for GNOME (versions 42 and below).

## Installation

Go to the [Sound Output Device Chooser extension page](https://extensions.gnome.org/extension/906/sound-output-device-chooser/) and toggle the install icon to add it to your system.

## Recommended Settings

Once installed, apply the following configuration settings for the best experience:

- **Integrate selector with slider:** Off
- **Hide selector if there is only one device:** Off
- **Display audio profiles for selection:** On
- **Omit device origins at volume menu:** On
- **Extend volume menu to fit device names:** Off
