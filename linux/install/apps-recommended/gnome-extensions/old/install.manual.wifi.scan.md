# Manual Wi-Fi Scan Gnome Extension

> **Note:** Newer GNOME versions perform Wi-Fi scanning every 15 seconds by default, making
> this extension unnecessary.

To install the extension for GNOME <= 42, go to the
[Refresh Wi-Fi Connections](https://extensions.gnome.org/extension/905/refresh-wifi-connections/)
page on GNOME Extensions and toggle the install icon.
