# Install System Monitor (GNOME Extension)

[System Monitor Extension](https://extensions.gnome.org/extension/6807/system-monitor/)
**UUID:** `system-monitor@gnome-shell-extensions.gcampax.github.com`

## Prerequisite Application

Before installing the extension, you must install the GNOME System Monitor. Run the following command:

```bash
sudo apt install gnome-system-monitor
```

## Settings

- Uncheck **"Swap"** by right-clicking on the tool (`show-swap false`).
