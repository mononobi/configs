# GNOME Shell Theme Changer

## Extension Installation

1. Navigate to the [User Themes extension page](https://extensions.gnome.org/extension/19/user-themes/) and toggle the install icon.
2. Once installed, you can download new shell themes and icon themes from [GNOME Look](https://www.gnome-look.org/).

## Theme Installation

### For Icon Themes

1. Extract the downloaded archive.
2. Move the top two folders into your user's icons directory:
   `~/.icons`

### For Shell Themes

1. Extract the downloaded archive.
2. Move the top folder into your user's themes directory:
   `~/.themes`

## Applying Themes

After installing the themes in their respective folders, open the **Tweaks** application and navigate to the **Appearance** tab to change both your icons and shell theme.
