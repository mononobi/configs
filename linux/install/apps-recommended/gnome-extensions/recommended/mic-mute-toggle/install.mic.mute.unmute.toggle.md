# Install Mic Mute Toggle Extension

This extension adds a mic mute/unmute toggle to the top panel.

## Installation Instructions

Go to the ['Nothing to Say' extension page](https://extensions.gnome.org/extension/1113/nothing-to-say/) and toggle the install icon.

## Recommended Settings

Configure the extension with the following settings:

- **Keybindings:** `<Ctrl>F9` (Or any key which has the mute sound icon)
- **Top bar icon:** Always
- **OSD notification:** checked
- **Sound notification:** checked
