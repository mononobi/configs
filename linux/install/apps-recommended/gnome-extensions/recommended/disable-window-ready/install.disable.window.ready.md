# Install Disable Window Ready Notification Extension

To disable the "Window is ready" notification, you can install one of the following GNOME extensions depending on your GNOME version:

*   **For GNOME <= 42:** Go to the [NoAnnoyance](https://extensions.gnome.org/extension/2182/noannoyance/) extension page and toggle the install icon.
*   **For GNOME >= 45:** Go to the [Steal My Focus Window](https://extensions.gnome.org/extension/6385/steal-my-focus-window/) extension page and toggle the install icon.
