# Quick Settings Tweak Extension

> **Note:** This extension moves the notifications and media player controls to the quick
> settings panel (right) from the date panel (center). It also adds the sound profile name
> on top of the volume slider. You can configure its settings after installation.

## Installation Instructions

### Gnome versions 43 to 48

Go to
[Quick Settings Tweaker on GNOME Extensions](https://extensions.gnome.org/extension/5446/quick-settings-tweaker/)
and toggle the install icon.

### Gnome versions 48 to 50

Download the extension zip file from the link below and follow the instructions to install
it. This is a community fork from the same extension, modified to work with newer Gnome
versions:

[jstockdale/quick-settings-tweaks Releases](https://github.com/jstockdale/quick-settings-tweaks/releases)

---

## Recommended Settings

It is recommended to enable the following settings for both versions (disable all others):

### Widgets Tab

- **Media Widget:** `On`
  - _All check-boxes:_ `On`
- **Notifications Widget:** `On`
  - _Use native controls:_ `Off`
  - _All other check-boxes:_ `On`
  - _Max height:_ `438`
- **Weather Widget:** `Off`
- **Volume Mixer Widget:** `Off`

### Toggles Tab

- **DND Quick Toggle:** `On`
- **Unsafe Mode Quick Toggle:** `Off`
