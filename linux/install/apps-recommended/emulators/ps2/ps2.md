# PS2 Emulator Installation (PCSX2)

PCSX2 is a PlayStation 2 emulator.

## Installation

Run the following command to install PCSX2 via Flatpak:

```bash
flatpak install flathub net.pcsx2.PCSX2
```

## Configuration

After installing the emulator, you must copy and extract the PS2 BIOS files into the
application's BIOS directory.

> **Note:** The BIOS files are located at `files/ps2.bios.zip`.

To locate the BIOS directory in the application, navigate to: **Settings -> BIOS -> BIOS
Directory**
