# PS3 Emulator Installation Guide

## 1. Download the Emulator

To get the PS3 emulator, visit the official website and download the latest build for your
system:

> [RPCS3 Download Page](https://rpcs3.net/download)

## 2. Download the Firmware

Download the latest PS3 firmware from the following link:

> [PlayStation 3 System Software](https://www.playstation.com/en-us/support/hardware/ps3/system-software/)

## 3. Make the Emulator Executable

Make the downloaded emulator file executable by running the following command:

```bash
sudo chmod a+x FILE_NAME
```

## 4. Install the Firmware

After running the emulator, install the downloaded firmware to start gaming. Navigate to:
`File > Install Firmware`
