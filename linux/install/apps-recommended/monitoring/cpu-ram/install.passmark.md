# PassMark PerformanceTest

> **Note:** PassMark is a CPU and memory benchmarking and comparing tool.

## Prerequisites

You need to install this library to be able to use PassMark:

```bash
sudo apt-get install libncurses5
```

## Installation

Go to the [PassMark Linux Download Page](https://www.passmark.com/products/pt_linux/index.php)
and download the Linux version.

Execute this command to make the downloaded file executable:

```bash
sudo chmod 775 file_name
```

## Usage

Execute this to start benchmarking:

```bash
./file_name
```
