# Install Poedit

> **Note** Flatpak is the recommended way to install.

## Flatpak Installation (Recommended)

```bash
flatpak install flathub net.poedit.Poedit
```

## Snap Installation

> **Warning** You can also install using Snap, but it is not recommended at all as it has
> terrible performance. Always check for the latest channel before installing.

```bash
snap info poedit
sudo snap install poedit --channel=latest/stable
```

## APT Installation

> **Warning** APT install is not recommended and provides an obsolete version.

```bash
# sudo apt-get install poedit
```
