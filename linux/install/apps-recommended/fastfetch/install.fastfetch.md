# Install Fastfetch

Fastfetch is a maintained, fast, C-based system information tool and serves as a successor to
Neofetch. It is available in the default repositories for Ubuntu 24.04 and later, or via an
official PPA for earlier releases.

## For Ubuntu 24.04+

```bash
sudo apt-get update
sudo apt-get install -y fastfetch
```

## For Ubuntu 22.04 and Earlier

```bash
# sudo add-apt-repository -y ppa:zhangsongcui3371/fastfetch
# sudo apt-get update
# sudo apt-get install -y fastfetch
```
