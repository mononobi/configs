# Audacity Installation Guide

Audacity is a comprehensive audio editing and mixing tool.

> **Note:** The APT package version of Audacity is obsolete and not recommended for
> installation.

## Installation via AppImage

1. Visit the [official Audacity download page](https://www.audacityteam.org/download/) and
   download the latest AppImage.
2. Make the downloaded file executable by running the following command (replace
   `file_name` with the actual name of the downloaded file):

```bash
sudo chmod 775 file_name
```

3. Run the AppImage to launch the application.
