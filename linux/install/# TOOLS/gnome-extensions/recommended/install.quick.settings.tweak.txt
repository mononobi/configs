# This extension moves the notifications and media player controls to
# the quick settings panel (right) from date panel (center).
# it also adds the sound profile name on top of volume slider.
# you can configure its settings after installation.

########## 43 <= Gnome <= 48:
# Go to 'https://extensions.gnome.org/extension/5446/quick-settings-tweaker/'
# page and toggle the install icon.

########## 48 <= Gnome <= 50:
# Download the extension zip file from this link and follow the instructions to install it.
# This is a community fork from the same extension which is modified to work with newer Gnome
# versions:
# https://github.com/jstockdale/quick-settings-tweaks/releases

# Recommended settings to enable for both (disable others):

######################## Widgets Tab ########################

#### Media Widget -> On
# All check-boxes -> On

#### Notifications Widget -> On
# Use native controls -> Off
# All other check-boxes -> On
# Max height: 438

#### Weather Widget -> Off

#### Volume Mixer Widget -> Off

######################## Toggles Tab ########################

# DND Quick Toggle -> On
# Unsafe Mode Quick Toggle -> Off

#################################################################################################
