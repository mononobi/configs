# Tar Gzip Archive Compression & Extraction

Commands for creating and extracting compressed `.tar.gz` archives using `tar`.

| Action                        | Command                                               |
| :---------------------------- | :---------------------------------------------------- |
| **Compress File / Directory** | `tar -czf <ARCHIVE_NAME.tar.gz> <SOURCE_FILE_OR_DIR>` |
| **Extract Archive**           | `tar -xf <ARCHIVE_NAME.tar.gz>`                       |
