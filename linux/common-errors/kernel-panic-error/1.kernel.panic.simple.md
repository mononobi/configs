This most commonly occurs when a background kernel update is interrupted or fails to generate 
the `initramfs` properly, leaving the system without the necessary drivers to read your 
hard drive during boot.

Here is the quickest way to fix it:

### 1. Boot Using an Older Kernel

1. Reboot the PC.
2. Immediately after your motherboard splash screen, hold down the **Shift** key 
   (or rapidly tap **Esc**) to bring up the GRUB boot menu.
3. Select **Advanced options for Ubuntu**.
4. Choose an older kernel version from the list (pick the second or third standard 
   option down, avoiding the top one and any labeled "recovery mode") and press **Enter**.

### 2. Repair the Broken Kernel

Once your system successfully boots to the desktop using the older kernel, you need to 
repair the configuration for the newest one.

1. Open your terminal.
2. Regenerate the `initramfs` for all installed kernels to ensure the NVMe drivers 
   are properly packed:
```bash
sudo update-initramfs -u -k all
```

3. Update GRUB to refresh the bootloader entries:
```bash
sudo update-grub
```

4. Reboot the PC normally. It will now automatically default to the repaired, newest kernel.

> NOTE: 
> If for any reason none of the older kernels in the GRUB menu will boot, the next step would 
> be to boot from an Ubuntu Live USB, mount your root partition, `chroot` into your system, and 
> execute the exact same terminal commands.
