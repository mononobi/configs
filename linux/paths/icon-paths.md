# Standard Linux Application Icon Paths

Standard filesystem locations where desktop environments search for application icons:

- **System-Wide Pixmaps**: `/usr/share/pixmaps`
- **System-Wide Icon Themes**: `/usr/share/icons`
- **Application-Specific Data**: `/usr/share/<APP_NAME>/`
- **User-Specific Icon Themes**: `~/.local/share/icons`
- **Legacy User Icons**: `~/.icons`
