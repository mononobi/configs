# Key Linux Configuration File Paths

A reference of standard system configuration directories and files in Debian/Ubuntu
environments.

| Configuration Area             | File / Directory Path      |
| :----------------------------- | :------------------------- |
| **APT Repositories (Global)**  | `/etc/apt/sources.list`    |
| **APT Repositories (Modular)** | `/etc/apt/sources.list.d/` |
| **Active DNS Resolvers**       | `/etc/resolv.conf`         |
| **Name Service Switch**        | `/etc/nsswitch.conf`       |
| **Static Host Lookup**         | `/etc/hosts`               |
| **Nginx Server Blocks**        | `/etc/nginx/conf.d/`       |
| **Cron Scheduling**            | `/etc/cron.d/`             |
| **SSH Daemon (Defaults)**      | `/etc/ssh/sshd_config`     |
| **SSH Daemon (Modular)**       | `/etc/ssh/sshd_config.d/`  |
