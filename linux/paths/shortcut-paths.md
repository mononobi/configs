# Standard Desktop Shortcut (`.desktop`) Paths

Locations where desktop environments discover application launchers:

- **System-Wide APT Packages**: `/usr/share/applications`
- **Per-User Custom Launchers**: `~/.local/share/applications`
- **System-Wide Flatpak Applications**: `/var/lib/flatpak/exports/share/applications`
- **Per-User Flatpak Applications**: `~/.local/share/flatpak/exports/share/applications`
- **Legacy GNOME Launchers**: `~/.gnome/apps`
