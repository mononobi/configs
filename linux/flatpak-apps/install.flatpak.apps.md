# Recommended Flatpak Applications Installation

Install popular desktop applications and developer tools via Flathub using Flatpak.

## Batch Installation

To install all recommended applications in one command, execute:

```bash
flatpak install -y flathub \
  org.mozilla.firefox \
  org.videolan.VLC \
  org.libreoffice.LibreOffice \
  org.gnome.Shotwell \
  com.transmissionbt.Transmission \
  org.remmina.Remmina \
  net.poedit.Poedit \
  org.atheme.audacious \
  org.gimp.GIMP \
  org.kde.kolourpaint \
  org.mypaint.MyPaint \
  com.getpostman.Postman \
  org.signal.Signal \
  org.telegram.desktop \
  com.visualstudio.code \
  org.chromium.Chromium \
  us.zoom.Zoom \
  net.sourceforge.squirrel_sql \
  fr.handbrake.ghb \
  org.blender.Blender \
  com.anydesk.Anydesk \
  org.gnome.Maps \
  nl.g4d.Girens \
  io.qt.QtCreator \
  chat.delta.desktop \
  org.gnome.Weather \
  nl.hjdskes.gcolor3 \
  com.usebottles.bottles \
  com.github.tchx84.Flatseal \
  org.gnome.NetworkDisplays
```
