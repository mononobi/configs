# Microsoft SQL Server Default Credentials

Baseline connection credentials and instance defaults for development instances.

| Parameter                 | Value         |
| :------------------------ | :------------ |
| **Port**                  | `1433`        |
| **Database User (SA)**    | `sa`          |
| **Database Password**     | `123`         |
| **Default Database**      | `master`      |
| **Default Instance Name** | `MSSQLSERVER` |
